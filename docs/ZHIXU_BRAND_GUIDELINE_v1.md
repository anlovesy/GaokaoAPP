# ZHIXU Brand Guideline v1.0

## 1. Brand Definition

**中文名**：志序  
**英文名**：ZHIXU  
**副标题**：AI College Decision Studio  
**品牌精神**：Every future deserves a better decision.

### 1.1 Brand Position

ZHIXU 不是教育网站，不是填报系统，也不是通用学习平台。  
ZHIXU 是一个帮助年轻人完成重要人生决策的 Premium AI 决策顾问品牌。

### 1.2 One-Line Description

帮助每一位考生完成人生第一场真正重要的战略决策。

### 1.3 What ZHIXU Is Not

- 不是培训机构
- 不是高校官网
- 不是国产 SaaS
- 不是后台管理系统
- 不是单纯的志愿推荐工具

### 1.4 What ZHIXU Is

- Premium AI College Decision Studio
- Strategic Decision Companion
- Quiet, intelligent, trustworthy digital brand

## 2. Brand Core

### 2.1 Brand Keywords

- Premium
- Minimal
- Strategic
- Editorial
- Calm
- Spatial
- Intelligent
- Trustworthy
- Human
- Future-facing

### 2.2 Brand Personality

- 冷静，但不冷漠
- 专业，但不压迫
- 高级，但不炫耀
- 智能，但不机械
- 有判断力，但不说教

### 2.3 Brand Promise

把每一分，都放在更对的位置。  
Place every point where it belongs.

## 3. Brand Story

人生的重要选择，不应该只是填写一张志愿表。  
AI 的价值，不在替用户做决定，而在帮助用户理解自己、理解学校、理解未来，并最终找到属于自己的路径。

“志序”中的“志”代表志向，“序”代表顺序、策略与判断。  
品牌的核心，不是给出一个答案，而是建立一种更好的决策方式。

## 4. Design Principles

### 4.1 Less Interface, More Experience

尽量减少表面 UI 的存在感，让内容、判断和情绪成为主角。

### 4.2 Quiet Confidence

所有视觉表达都应体现克制和把握感，而不是推销感。

### 4.3 Precision With Humanity

数据与算法应被表达为“可信赖的帮助”，而不是“冰冷的机器”。

### 4.4 Spatial Clarity

通过留白、层级、节奏和空间建立秩序，而不是通过过多边框和组件堆砌。

## 5. Recommended Brand Direction

### 5.1 Primary Direction

**Quiet Strategy**

参考气质：

- Apple
- Linear
- Anthropic
- Arc Browser

### 5.2 Why This Direction

- 最容易建立高信任感
- 最适合家长、学生和咨询机构同时接受
- 最能避免教育网站和后台系统气质
- 最适合和“志序”的中文语义融合

## 6. Logo Strategy

### 6.1 Logo Goal

Logo 不应直接表达“教育”，而应表达“决策秩序”。

### 6.2 Avoid

- 毕业帽
- 书本
- 机器人
- 聊天气泡
- AI 脑图形
- 灯泡
- 校园建筑
- 地球
- 奖杯
- 任何行业化教育符号

### 6.3 Required Traits

- Abstract Geometry
- Minimal
- International
- Spatial
- Premium
- App-icon ready
- Favicon ready

### 6.4 Recommended Concept System

主品牌逻辑：**Sequence**  
图标识别逻辑：**Hidden Z**  
动效母体逻辑：**Node + Path**

## 7. Logo Concepts

### 7.1 Concept A: Node + Path

语义：路径、节点、方向、最优解

适合：

- Loading
- AI Advisor 动效
- 品牌说明动画

### 7.2 Concept B: Hidden Z

语义：通过几何留白隐藏 Z

适合：

- Favicon
- App Icon
- Header mark

### 7.3 Concept C: Sequence

语义：顺序、层级、判断、落点

适合：

- 主 Logo
- 品牌主图形
- PPT 封面

### 7.4 Concept D: Decision Orbit

语义：围绕核心变量进行校准后的决策轨道

适合：

- 深色模式
- 动效
- AI 相关品牌场景

## 8. Geometry Rules

### 8.1 Base Grid

- 8px system grid
- 24x24 icon grid
- 32x32 or 40x40 logo construction grid

### 8.2 Clear Space

Logo 周围最小留白等于 Logo 主笔画厚度的 1.5 倍。

### 8.3 Minimum Size

- Screen: 16px
- Print: 10mm

### 8.4 Construction

- 所有图形必须由稳定几何关系构成
- 不允许随意视觉拼贴
- 不允许复杂装饰性线条

## 9. Color System

### 9.1 Primary Palette

| Token | Hex | Usage |
|---|---|---|
| Ink Navy | `#10243A` | Brand identity, primary text, hero contrast |
| Slate Blue | `#536D89` | Secondary text, supporting surfaces |
| Warm Coral | `#FF6B4A` | CTA, emphasis, active states |
| Paper White | `#F7F8FA` | Main background |
| Mist Gray | `#E8EDF2` | Borders, light surfaces, dividers |

### 9.2 Extended Neutrals

| Token | Hex | Usage |
|---|---|---|
| Soft Silver | `#C8D1DA` | Soft strokes, disabled, icon support |
| Quiet Gray | `#7A8795` | Captions, metadata |

### 9.3 Color Rules

- 品牌中主色不超过 20% 页面面积
- Accent 色只用于关键行为和强调
- 不允许使用高饱和多彩组合
- 不允许使用教育行业常见亮蓝渐变
- 保持整体冷静、中性、克制

### 9.4 Approved Combinations

1. Light Interface  
Background `#F7F8FA` + Text `#10243A` + Accent `#FF6B4A`

2. Editorial Canvas  
Background `#F3EEE5` + Text `#10243A` + Support `#536D89`

3. Dark Premium  
Background `#0D1724` + Text `#F7F8FA` + Accent `#FF6B4A`

## 10. Typography System

### 10.1 Primary Fonts

| Role | Recommended | Backup |
|---|---|---|
| English Sans | Geist | General Sans / Satoshi |
| Chinese Sans | MiSans VF | HarmonyOS Sans SC |
| Display Serif | Canela | PP Editorial New |

### 10.2 Usage Principle

- Sans 用于 UI、正文、导航、按钮
- Display Serif 只用于少量品牌展示标题
- 不超过 2 个字体家族同时出现于一个页面

### 10.3 Type Scale

| Level | Size | Line Height | Usage |
|---|---|---|---|
| Display XL | 96 | 104 | Hero |
| Display L | 72 | 80 | Section hero |
| H1 | 56 | 64 | Page titles |
| H2 | 40 | 48 | Major section title |
| H3 | 28 | 36 | Content section |
| Body L | 20 | 32 | Intro text |
| Body | 16 | 28 | Main body |
| Caption | 13 | 20 | Metadata |
| Label | 12 | 18 | Labels |
| Button | 14 | 20 | CTA |

### 10.4 Typography Rules

- 中文正文优先清晰和稳定
- 大标题允许更紧的字距
- 正文避免过轻字重
- 全大写仅用于标签与辅助信息
- 一屏只允许一个 typographic hero

## 11. Icon System

### 11.1 Style

- Apple clarity
- Linear precision
- Raycast sharpness

### 11.2 Rules

- Base grid: 24px
- Sizes: 24 / 20 / 16
- Stroke: 1.75px
- Rounded ends
- Monochrome first

### 11.3 Avoid

- Material Icons 混用
- Heroicons 混用
- 粗细不统一
- 填充与线性风格无规则混用

## 12. Motion Identity

### 12.1 Logo Motion

- Stroke draw
- Dot pulse
- Direction reveal
- Soft glow
- Fade settle

### 12.2 Interface Motion

- Scroll reveal
- Hover lift
- Image float
- Mouse glow
- Magnetic button
- Smooth transition
- Parallax

### 12.3 Motion Rules

- 轻，不夸张
- 慢，不跳
- 柔和，不生硬
- 统一 easing
- 统一节奏

### 12.4 Recommended Timing

- Hover: 0.24s - 0.32s
- Enter: 0.6s - 0.9s
- Page transition: 0.8s - 1.1s
- Ease: `cubic-bezier(0.22, 1, 0.36, 1)`

## 13. Photography Guideline

### 13.1 Style Direction

- 统一冷暖色调
- 统一曝光
- 统一裁切比例
- 统一景深
- 统一 LUT

### 13.2 Desired Mood

- 清晨 / 黄昏光线
- 校园建筑与人文环境并重
- 安静、克制、电影感

### 13.3 Avoid

- 招生宣传册既视感
- 高饱和广告片色彩
- 杂乱背景
- 低质量网络图

## 14. Glass System

### 14.1 Surface Definition

- Blur: 18px - 30px
- Hairline border
- Soft ambient shadow
- Light reflection
- Slight warm/cool tint

### 14.2 Avoid

- 普通 Tailwind 卡片
- 纯白硬卡
- 厚边框
- 重阴影

## 15. Component Tone

### 15.1 Buttons

- 应像品牌动作，而不是普通按钮
- 主按钮具有方向感和焦点感

### 15.2 Inputs

- 安静、极简、低干扰

### 15.3 Cards

- 更像表面层级，而不是信息容器堆叠

### 15.4 Navigation

- 最少化
- 不后台化

## 16. Voice & Language

### 16.1 Voice Attributes

- Clear, not simplistic
- Calm, not cold
- Strategic, not preachy

### 16.2 Copywriting Rules

- 标题短句化
- 少解释，多判断
- 不使用行业套话
- 不使用教育培训文案风格

## 17. Brand Applications

### 17.1 Website

- Logo 是签名，不是装饰
- 留白优先于功能密度

### 17.2 Landing

- 一个核心标题
- 一个副标题
- 一个动作
- 品牌图像做氛围，不做说明

### 17.3 Login

- 像品牌门厅，不像系统入口

### 17.4 Workspace

- 品牌感降低，产品感提高
- 但不能退化为后台视觉

### 17.5 AI Advisor

- 更像高级顾问空间
- 不像客服对话窗

### 17.6 Loading / Splash

- 使用 Logo motion 建立品牌记忆

### 17.7 App Icon / Favicon

- 优先使用 Hidden Z 或 Sequence 变体

## 18. Review Standard

ZHIXU 的品牌标准必须达到：

- Premium
- International
- Memorable
- Scalable
- Motion-ready
- Website-ready
- App-icon-ready

如果最终效果仍然像：

- 教育网站
- 后台系统
- 培训机构
- 国产 SaaS

则视为品牌系统不合格，需继续优化。
