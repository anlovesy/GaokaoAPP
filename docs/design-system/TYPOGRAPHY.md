# TYPOGRAPHY

## Purpose

Typography is the primary carrier of authority and premium tone in this product.

## Type Roles

### Display

Primary:

- `Inter Tight`
- `Plus Jakarta Sans` as acceptable secondary display reference if needed

Use for:

- hero headlines
- page titles
- key premium statements

Character:

- tight
- assertive
- contemporary
- editorial

### Body

Primary:

- `Noto Sans SC`

Use for:

- paragraph text
- labels
- form content
- system copy

Character:

- clean
- stable
- highly legible in Chinese

### Utility

Primary:

- `JetBrains Mono`

Use for:

- data fragments
- timestamps
- small metadata
- technical or structured labels

## Type Scale

### Desktop

- Display XL: `96px - 120px`
- Display L: `72px - 88px`
- Heading 1: `48px - 64px`
- Heading 2: `32px - 40px`
- Heading 3: `24px - 28px`
- Body L: `20px - 22px`
- Body M: `16px - 18px`
- Body S: `14px`
- Utility XS: `12px`

### Mobile

- Display XL: `48px - 64px`
- Display L: `40px - 48px`
- Heading 1: `32px - 40px`
- Heading 2: `24px - 28px`
- Heading 3: `20px - 22px`
- Body L: `18px`
- Body M: `16px`
- Body S: `14px`
- Utility XS: `12px`

## Weight Guidance

- Display: `600 - 700`
- Headings: `600`
- Body: `400 - 500`
- Utility: `500`

## Line Height

- Display: `0.92 - 1.02`
- Headings: `1.05 - 1.15`
- Body: `1.5 - 1.7`
- Utility: `1.3 - 1.5`

## Letter Spacing

- Display may use slight negative tracking
- Body should remain neutral
- Utility may use light positive tracking if needed

## Typography Rules

- Headlines must be visually dominant.
- Do not compress large Chinese headlines with tight containers.
- Do not stack too many weights on the same screen.
- Do not use typography as generic filler.
