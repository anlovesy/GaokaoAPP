# COLOR_SYSTEM

## Purpose

This document defines the approved color palette and usage rules.

## Core Palette

### Brand Core

- Midnight Ink: `#0B1720`
- Deep Teal: `#123847`
- Ocean Slate: `#1A667D`
- Porcelain Mist: `#F6F8FA`
- Soft Slate: `#C9D3DA`
- Signal Coral: `#FF6B4A`

## Functional Roles

### Background

- Primary background: `#F6F8FA`
- Deep immersive background: `#0B1720`

### Text

- Primary text on light: `#0F172A`
- Secondary text on light: `#4B5B66`
- Primary text on dark: `#F6F8FA`
- Secondary text on dark: `rgba(246, 248, 250, 0.72)`

### Accent

- Action accent: `#FF6B4A`
- Cool accent: `#1A667D`

### Surface

- Elevated light surface: `rgba(255, 255, 255, 0.72)`
- Elevated dark surface: `rgba(11, 23, 32, 0.54)`
- Hairline border light: `rgba(15, 23, 42, 0.08)`
- Hairline border dark: `rgba(246, 248, 250, 0.12)`

## Gradients

Allowed usage:

- soft teal to transparent glow
- coral accent halo for CTA emphasis
- muted atmospheric radial backgrounds

Avoid:

- rainbow gradients
- neon purple default SaaS gradients
- high-saturation backgrounds covering full content areas

## State Colors

- Success should be calm and muted, not bright green by default.
- Warning should be restrained.
- Error should remain clear but not overpower the layout.

## Usage Rules

- Coral must be rare and meaningful.
- Deep teal and ink should establish trust and structure.
- Light backgrounds should dominate most customer-facing experiences.
- Strong dark modes may be used selectively, not automatically everywhere.
