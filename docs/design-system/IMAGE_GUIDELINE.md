# IMAGE_GUIDELINE

## Purpose

Images are a primary emotional layer in this product.

## Image Role

Images should:

- establish trust
- create atmosphere
- communicate seriousness
- support premium storytelling

Images should not:

- behave like generic banners
- feel like school brochure clichés
- become filler behind text

## Image Types

Preferred:

- real campus architecture
- iconic university landmarks
- library interiors
- courtyards
- lecture spaces
- corridors
- urban context around campus

Avoid:

- certificates
- diploma placeholders
- generic smiling students
- handshake or office stock photos
- unrelated lifestyle hero images

## Mapping Rules

- Each university must map to its own image set whenever possible.
- Never let all schools render the same fallback image.
- Use structured image folders and deterministic naming.
- Prefer `cover`, `campus`, `gate`, `library`, `banner`, `thumbnail` conventions.

## Cropping Rules

- Favor cinematic wide crops for hero media.
- Keep architectural lines readable.
- Do not crop key campus identity elements out of frame.
- Detail images may be tighter, but should still feel intentional.

## Visual Treatment

- Soft contrast
- Natural light
- Clean color grading
- Minimal oversaturation
- Subtle hover scale only

## Performance Rules

- Use lazy loading by default where appropriate
- Use placeholder strategy for slower media
- Avoid image flicker and incorrect cache reuse
- Maintain stable layout dimensions
