# SPACING_SYSTEM

## Purpose

Spacing is a structural tool for hierarchy and brand tone.

## Spacing Scale

Use an 8-point base system:

- `4`
- `8`
- `12`
- `16`
- `24`
- `32`
- `40`
- `48`
- `64`
- `80`
- `96`
- `120`
- `160`

## Screen Rhythm

### Macro Spacing

Use large spacing for:

- page sections
- hero to secondary transition
- layout breathing room

Preferred macro values:

- `64`
- `80`
- `96`
- `120`
- `160`

### Micro Spacing

Use small spacing for:

- icon to label
- title to supporting line
- list item rhythm

Preferred micro values:

- `8`
- `12`
- `16`
- `24`

## Layout Rules

- Increase whitespace before adding containers.
- If the page feels crowded, remove elements before shrinking spacing.
- Primary hero sections should feel oversized.
- Secondary information should step back through spacing, not only color.

## Mobile Rules

- Preserve breathing room on mobile.
- Do not collapse all spacing into dense app-like stacks.
- Reduce scale carefully, not mechanically.

Recommended mobile section spacing:

- `32`
- `40`
- `48`
- `64`

## Grid Guidance

- Avoid equal-width repetition as the default layout solution.
- Use asymmetry where the page concept benefits from it.
- Allow dominant visual areas and quieter support areas.
