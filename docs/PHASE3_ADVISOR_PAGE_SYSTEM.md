# Phase 3 AI Advisor Page System

## Objective

Evolve the advisor page into a full-screen AI decision studio.

Its role is not to imitate a chat app.
Its real job is:

`make the user feel the AI is reasoning, prioritizing, and reshaping the decision path in real time`

The page should feel like:

- an AI control center
- a calm reasoning chamber
- a premium desktop companion

It should not feel like:

- WeChat
- customer service
- a customer support ticket tool
- a narrow mobile messenger

---

## Page Role

The Advisor Page is the active cognitive layer of the product.

If Workspace is the planning studio and Volunteer is the ordering board,
then Advisor is:

`the live reasoning engine that interprets and redirects the next move`

This page answers:

`What is the AI thinking right now, and what should I do next?`

---

## Core Layout

### Desktop Ratio

- Left Context Rail: `18%`
- Main AI Chamber: `58%`
- Right Suggestion Stack: `24%`

### Layout Principle

- Left: conversation memory and user context
- Center: AI Orb, live reasoning stream, and response canvas
- Right: prompts, references, confidence changes, and suggested actions

### Spatial Behavior

- outer padding: `48 - 64`
- rail gap: `28 - 32`
- core vertical gap: `28 - 36`
- message spacing: `18 - 24`

The orb and reasoning stream must form the visual center.

---

## Core Sections

### 1. Context Rail

Content:

- Candidate identity
- Current score / rank
- Current decision focus
- Recent path changes

Purpose:

- keep the conversation grounded in the user's real situation

Rules:

- short, compressed, and quiet
- no dense tag cloud
- no dashboard metric overload

### 2. Orb Chamber

Content:

- large AI orb
- orbital rings
- soft particles
- state label

Purpose:

- become the single most iconic element of the page
- visually communicate “AI is thinking”

Rules:

- orb should occupy strong vertical space
- stronger than any bubble or text box
- this is the emotional center of the page

### 3. Reasoning Stream

Content:

- Current Thinking
- Key Interpretation
- Next Judgment
- one flowing response surface

Purpose:

- replace traditional chat bubbles with a more editorial, more immersive reasoning stream

Rules:

- not left-right message bubbles
- not a transcript wall
- use layered text blocks and subtle path markers

### 4. Source and Focus Panel

Content:

- Current Focus
- Referenced variables
- Recent comparison
- risk change note

Purpose:

- give structure to the AI's active reasoning inputs

Rules:

- small and supporting
- should not compete with the orb and reasoning stream

### 5. Prompt Deck

Content:

- quick prompts
- compare prompts
- sequencing prompts
- clarification prompts

Purpose:

- reduce user friction
- provide premium guided actions

Rules:

- more like command chips than chat shortcuts
- minimal quantity

### 6. Orb Input Plane

Content:

- glass input line
- send trigger
- voice / attach placeholders if needed visually

Purpose:

- preserve the existing interaction entry
- integrate input into the orb system instead of into a generic chat footer

Rules:

- wide and minimal
- fixed as part of the chamber composition

---

## Visual Language

The Advisor Page must intensify the shared ZHIXU language:

- Orbit
- Path
- Connection
- Decision

Mapping:

- orb = living intelligence core
- rings = reasoning cycles
- stream = interpretation path
- prompt deck = guided intervention layer
- context rail = stable human anchor

---

## Surface Rules

- Base canvas: warm fog gradient
- Orb chamber: deep navy glass
- Reasoning surfaces: pale translucent white
- Side rail surfaces: neutral soft glass

### Border

- hairline only
- soften contrast further than other pages

### Shadow

- glow-based depth
- avoid hard floating card shadows

### Radius

- chamber: `38 - 44`
- content plates: `26 - 32`
- prompt pills: `18 - 22`

---

## Typography

### Display

- 52 - 60px
- restrained semibold

### Chamber Heading

- 26 - 32px

### Body

- 17 - 18px

### Caption

- 12 - 14px

Rules:

- conversation should read like an editorial AI narrative
- avoid bold-heavy bubble UI typography

---

## Motion Intent

The final implementation should support:

- orb breathing
- orbit rotation
- soft particle drift
- reasoning text reveal
- input glow on focus
- prompt hover lift
- confidence flicker / update shimmer

Motion here is essential to meaning.

---

## Exit Criteria

This page is complete when:

1. it no longer resembles a conventional chat application
2. the orb becomes the unmistakable signature of the AI experience
3. the user can sense the AI's current reasoning state before reading every word
4. the page still belongs visually to Workspace, Volunteer, and University
