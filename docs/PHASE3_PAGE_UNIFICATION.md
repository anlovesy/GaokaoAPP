# Phase 3 Page Family Unification

## Objective

Unify `Volunteer`, `University`, and `AI Advisor` into one page family.

These pages serve different functions, but they must all feel like extensions of the same premium AI product.

The family rule is:

`different tasks, one visual language`

---

## Shared Brand Language

Every page must visibly express:

- Orbit
- Path
- Connection
- Decision

### How Each Page Maps the Language

- Workspace: decision universe
- Volunteer: ordered decision path
- University: decision dossier
- Advisor: reasoning orbit

---

## Shared Structural Rules

### 1. Center Dominance

The center area is always the main stage.

- Left rails provide context
- Right rails provide support
- Center drives meaning

### 2. Editorial Hierarchy

- one core title
- one core sentence
- one primary visual thesis

Avoid:

- multiple equal-weight modules
- dashboard repetition
- dense card grids

### 3. Surface Hierarchy

- warm canvas below
- pale glass for analytical surfaces
- deep navy glass for AI / active reasoning surfaces

### 4. Decision-First Interaction

Pages should always answer:

- what is being judged
- what changes if I act
- what the AI recommends next

---

## Shared Component Family

### Stable Components

- editorial eyebrow
- restrained display title
- glass major plane
- status pill
- decision strip
- AI rail / orb chamber

### Prohibited Regression

Do not reintroduce:

- classic dashboard cards
- large tables as the main visual structure
- thick borders
- equal-width repeated modules
- chat-app bubbles as the dominant AI language

---

## Shared Typography Rules

- English utility labels: Geist / Inter
- Chinese body and headers: HarmonyOS Sans / MiSans / Source Han Sans

Hierarchy rule:

- Display for thesis
- Heading for section focus
- Body for calm explanation
- Caption for metadata

---

## Shared Color Rules

Primary family:

- `#F7F7F4`
- `#EDF1F5`
- `#DDE9F3`
- `#6480E1`
- `#14283F`

Support:

- warm fog grays
- soft blue-grays
- deep navy for AI surfaces

---

## Shared Motion Direction

Phase 4 should inherit these page-level intentions:

- path drawing
- orbital breathing
- subtle parallax
- reveal by depth
- hover lift
- glow-based focus

The product should move like a calm intelligence system, not like a marketing toy.

---

## Review Standard

The family is successful when:

1. switching pages never breaks the brand mood
2. each page has a distinct role but not a distinct brand
3. the product feels premium, editorial, and AI-native across all screens
