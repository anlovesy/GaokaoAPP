# ZHIXU Logo System: Decision Orbit v1.0

## 1. Final Selection

**Selected Concept**: Decision Orbit  
**Chinese Name**: 志序  
**English Name**: ZHIXU  
**Descriptor**: AI College Decision Studio

Decision Orbit 被选为最终方向，因为它最能同时表达：

- 决策中心
- 复杂变量围绕用户展开
- AI 帮助校准方向
- 从不确定走向明确

它不是教育行业图标，而是一个更像国际 AI 产品的抽象决策符号。

## 2. Core Idea

Logo 由三部分组成：

1. **Core Dot**  
代表用户本人，代表分数、兴趣、志向与现实条件的交汇点。

2. **Orbit Stroke**  
代表信息、变量、判断过程与推演路径。

3. **Directional Arrow**  
代表 AI 辅助后的方向校准，最终形成明确去向。

一句话解释：

> 用户站在决策中心，AI 帮助复杂信息围绕其重组，并指向更优未来。

## 3. Visual Semantics

### 3.1 What It Should Feel Like

- Calm
- Premium
- Intelligent
- Spatial
- Precise
- Human-centered

### 3.2 What It Must Avoid

- 教育平台既视感
- 机器人或 AI 脑图形
- 行业化装饰符号
- 太像导航或地图软件
- 太像天文科技公司通用图形

## 5. Geometry System

### 5.1 Construction Grid

- Base construction: 32x32 grid
- Core dot aligned to center axis
- Orbit stroke thickness must remain optically balanced
- Arrow head uses same visual stroke family as orbit tail

### 5.2 Composition Ratio

Recommended balance:

- Core dot diameter: 1 unit
- Orbit radius: 3.2 to 3.8 units
- Stroke thickness: 0.42 to 0.5 unit
- Arrow head length: 0.9 to 1.2 unit

### 5.3 Clear Space

Minimum clear space = 1.5x core dot diameter on all sides.

### 5.4 Minimum Size

- Screen symbol-only: 16px
- Screen lockup: 72px width minimum
- Print symbol-only: 10mm

## 6. Stroke Rules

### 6.1 Stroke Character

- Rounded cap
- Rounded join
- Smooth continuous motion
- No sharp mechanical corners except final directional emphasis

### 6.2 Optical Rules

- Orbit stroke should feel “drawn by intent”, not mathematically stiff
- Arrow direction should point to upper-right in default master version
- The logo must feel stable even when rotated is forbidden

## 9. Motion Identity for Logo

### 9.1 Motion Sequence

1. Core dot appears
2. Orbit stroke draws around it
3. Direction arrow resolves at the end
4. Soft glow fades out
5. Final logo settles in place

### 9.2 Motion Timing

- Dot in: 0.24s
- Orbit draw: 0.8s
- Arrow resolve: 0.26s
- Glow decay: 0.45s
- Total recommended: 1.2s - 1.6s

### 9.3 Motion Use Cases

- Loading screen
- Splash screen
- AI response “thinking”
- Page entry for Landing Hero

### 10.2 Secondary Use Cases

## 11. Don'ts

- 不旋转 logo
- 不将 orbit 改为闭环圆圈
- 不将箭头改为过大强调符号
- 不加多重渐变
- 不加外发光描边作为静态默认样式
- 不压缩或拉伸比例
- 不在繁杂照片上直接使用无容器版本

## 12. Brand Fit Review

### Why Decision Orbit works for ZHIXU

1. 它比 Sequence 更具 AI 品牌辨识度
2. 它比 Hidden Z 更有人生决策叙事
3. 它比 Node + Path 更适合成为主标
4. 它在动效、App Icon、Splash 上更统一

### Remaining Design Risk

唯一风险是过于科技化。  
因此在落地时必须搭配：

- 安静留白
- 低饱和色彩
- 高级字体系统
- 人文摄影

这样它才会成为 Premium AI 决策品牌，而不是普通科技公司。
