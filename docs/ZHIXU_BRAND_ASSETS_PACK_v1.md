# ZHIXU Brand Assets Pack v1.0

## Purpose

This asset pack contains the first usable SVG exports for the selected `Decision Orbit` identity system.

These assets are intended for:

- brand review
- website integration
- favicon and app icon preparation
- splash and loading usage

## Usage Guidance

### 1. Preferred Use

- `mark-ink` for light surfaces
- `mark-paper` for dark surfaces
- `mark-coral` for motion, loading, and emphasis only
- `horizontal` for desktop headers
- `vertical` for splash, onboarding, login identity blocks
- `favicon` for browser and compact icon use

### 2. Current Limitations

The symbol mark is fully vector-defined.  
The lockups currently use text elements with font family fallbacks.

For production-final export, the next recommended step is:

1. rebuild the lockups in Figma or Illustrator
2. convert wordmarks to outlines
3. export print-safe SVG/PDF variants

### 3. Color Rules

- Default static mark should remain `#10243A`
- Reverse mark should remain `#F7F8FA`
- Coral is an accent, not the main default logo fill

### 4. Application Priority

1. favicon and app icon
2. landing header
3. login identity
4. loading and splash
5. advisor motion state
