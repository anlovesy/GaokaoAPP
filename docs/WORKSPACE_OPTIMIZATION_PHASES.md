# Workspace Optimization Phases

## Goal

在不破坏现有业务逻辑、React 结构和数据接口的前提下，把整套高考志愿 AI 产品从“高级 Dashboard”升级为一套统一的 AI Native 品牌体验。

目标参考：

- Apple
- Federico Pian
- Linear
- Raycast
- Vercel
- OpenAI Desktop

核心原则：

- Brand First
- System Before Pages
- Motion Supports Meaning
- One Language Across All Screens

---

## Phase 1: Brand Identity

### Objective

建立整套产品的品牌视觉基础，让 Logo、字体、色彩、图形语言和页面气质形成统一来源。

### Deliverables

1. Brand Core
   - 品牌关键词
   - 品牌语气
   - 品牌情绪
   - 品牌使用场景

2. Logo Direction
   - `Decision Orbit` 主方向
   - 图标比例
   - 最小尺寸
   - 单色/反白/深底适配

3. Typography System
   - Display
   - Heading
   - Body
   - Caption
   - 中英文字体组合
   - 字重与层级规范

4. Color System
   - Warm White
   - Fog Gray
   - Blue Gray
   - Deep Navy
   - Accent Blue
   - 状态色

5. Brand Language
   - Orbit
   - Path
   - Connection
   - Decision

### Rules

- 所有页面必须共享同一品牌语义
- 不允许每页使用不同视觉母题
- Logo、Hero、Orb、Timeline、Hover、Loading 必须属于同一视觉体系

### Exit Criteria

- 看到任意页面局部，也能识别为同一个品牌
- 色彩、字体、图形语言不再像“拼装 UI”

---

## Phase 2: Workspace Design System

### Objective

把 Workspace 做成整套产品的系统母版，先定义组件语言，再扩展到其他页面。

### Deliverables

1. Layout System
   - 三栏比例
   - 宽度规则
   - 留白规则
   - 内容重心规则

2. Core Components
   - Candidate Capsule
   - Decision Universe
   - Today’s Insight
   - Confidence Block
   - Decision Timeline
   - AI Studio
   - Orb Input

3. State Rules
   - 默认态
   - Hover 态
   - Focus 态
   - Expanded 态
   - Loading 态

4. Card and Surface Rules
   - 透明度
   - 圆角
   - 描边
   - Glass 层
   - Depth 层

5. Timeline Rules
   - 节点样式
   - 图片比例
   - 风险标签语言
   - 展开逻辑

### Rules

- 不用普通信息卡片堆界面
- 不用 SaaS 样式组件思维
- 组件必须服务叙事，而不是只做容器

### Exit Criteria

- Workspace 具备完整的视觉母语
- 其他页面可直接复用其组件逻辑

---

## Phase 3: University / Volunteer / AI Advisor Unification

### Objective

把其他核心页面统一到同一品牌和系统语言下，避免首页高级、内页回到后台。

### Deliverables

1. University Page
   - Hero
   - 校园图片模块
   - 专业信息模块
   - 风险与录取模块
   - 交互细节

2. Volunteer Page
   - 志愿排序界面
   - 志愿对比界面
   - 冲稳保策略界面
   - 展开详情与排序交互

3. AI Advisor Page
   - 独立 AI Studio
   - Orb 主视觉
   - Thinking 状态
   - Suggestion Stream
   - Input System

4. Shared UI Language
   - 共用标题系统
   - 共用模块间距
   - 共用按钮系统
   - 共用风险与状态语言

### Rules

- 不允许出现“首页是品牌页，内页是后台页”
- University / Volunteer / Advisor 必须是同一个产品家族

### Exit Criteria

- 任何页面切换都不破坏品牌连续性
- 页面功能不同，但语言一致

---

## Phase 4: Motion System

### Objective

建立整套动效语言，让滚动、悬停、AI 动画和页面切换拥有统一规则，而不是随机加动效。

### Deliverables

1. Motion Principles
   - Calm
   - Premium
   - Deliberate
   - AI Native

2. Global Motion
   - 页面进入
   - 页面退出
   - Section Reveal
   - Scroll Reveal
   - Mouse Glow

3. AI Motion
   - Orb Breathing
   - Orbit Rotation
   - Particle Drift
   - Thinking Pulse
   - Path Drawing

4. Interaction Motion
   - Hover Lift
   - Magnetic Button
   - Card Expand
   - Timeline Progress
   - Input Focus Bloom

5. Motion Tech Mapping
   - Framer Motion
   - GSAP
   - Lenis
   - CSS Micro Motion

### Rules

- 动效必须解释系统在做什么
- 不用无意义的“装饰性乱动”
- Hero 动效、AI 动效、Hover 动效必须来自统一节奏

### Exit Criteria

- 用户感受到“系统正在思考”
- 动效不喧宾夺主，但足够有生命感

---

## Execution Order

1. Phase 1 先定品牌基础
2. Phase 2 用 Workspace 建立系统母版
3. Phase 3 把内页统一落地
4. Phase 4 最后统一注入动效系统

---

## Suggested Output For Each Phase

每一阶段都统一产出：

1. High-Fidelity Mockup
2. System Board
3. Component Notes
4. Comparison Against Current Version
5. Self Review Score
